# My C++ Theme

**Автор:** Маршлалов Игорь Сергеевич, группа М3114
**Название плагина:** my-cpp-theme
**Тип:** цветовая тема VS Code (Color Theme)

## Описание

`my-cpp-theme` — светлая бежевая тема оформления для Visual Studio Code,
для языка С++

## Возможности

- Бежевая светлая палитра интерфейса (редактор, боковая панель, статус-бар,
  activity bar, номера строк, выделение).
- Подсветка синтаксиса C++:
  - ключевые слова (`int`, `return`, `const`, `if`, `else` и т.д.);
  - имена функций;
  - строковые литералы и escape-последовательности;
  - числовые литералы;
  - комментарии (курсив);
  - типы, классы, пространства имён;
  - операторы и пунктуация.
- Подсветка JSON с чередованием цветов по уровням вложенности (9 уровней).
- Подсветка Markdown: заголовки, ссылки, цитаты, таблицы, блоки кода.
- Подсветка HTML и CSS.
- Совместимость со стандартными scope TextMate, поэтому тема корректно
  работает и с другими языками.

## Установка

### Из `.vsix`
1. Скачать `my-cpp-theme-0.0.1.vsix` из раздела **Releases**.
2. В VS Code: панель Extensions → `...` → **Install from VSIX** → выбрать файл.
3. Перезапустить VS Code.
4. `Cmd+K` `Cmd+T` → выбрать **My C++ theme**.
